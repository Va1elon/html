Безопасность

Устройства

Показывается текущая сохранённая сессия этого браузера. Для глобального списка всех устройств нужен Firebase/backend.

Правила

1. 📜 Общие положения
1.1. Использование устройства возможно только при наличии активной подписки.
1.2. Без подписки устройство блокируется.

2. 💨 Виды подписок
2.1. По сроку действия
Недельная — 7 календарных дней.
Месячная — 30 календарных дней.
2.2. По типу учёта дней
🛠️ Рабочая подписка — дни, включая выходные и перерывы, сгорают, даже если вы не парили.
🕊️ Свободная подписка — сгорают только те дни, в которых была хотя бы одна затяжка. Дни без парения не тратятся и переносятся.

3. ⏳ Продление и остатки
При оплате новой подписки остатки старой не суммируются. Переход с «Рабочей» на «Свободную» и обратно — только после истечения текущей подписки.

4. 🚫 Приостановка подписки при отсутствии жидкости
Если у владельца заканчивается жидкость, подписка пользователя приостанавливается без траты дней. Дни «замораживаются» до момента, когда жидкость снова появится.

5. ⚠️ Санкции за курение без подписки

Весь сайт уже находится в этом одном HTML-файле. Для безопасных аккаунтов и подписок Supabase нужно один раз создать таблицы.

1

2
Открой SupabaseВставь скопированный текст в SQL Editor и нажми Run.
3
Вернись и нажми «Проверить»После этого регистрация, вход, платежи и админка заработают глобально.
